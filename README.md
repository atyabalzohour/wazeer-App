# تطبيق وزير الحلو | Wazeer ElHelw Mobile App

تطبيق موبايل متكامل لطلب الحلويات والأطباق الشرقية والغربية من علامة **وزير الحلو**، مبني بتقنية **React Native & Expo** ومطابق 100% للتصاميم ودليل واجهة وتجربة المستخدم المعتمد.

## 📱 الشاشات والمميزات المكتملة

1. **الرئيسية (Home Screen)**:
   - شريط علوي مع سلة مشتريات تفاعلية، إشعارات، وشعار وزير الحلو، ومحدد موقع التوصيل السريع.
   - شريط بحث مباشر للمنتجات.
   - بانر ترويجي تفاعلي "أجمل الحلويات من وزير الحلو .. طعم لا يقاوم".
   - تصنيفات أفقية (حلويات، آيس كريم، مشروبات، وجبات).
   - قسم العروض المميزة (خصم 30%، عرض خاص 2 قطعة براونيز).
   - قائمة الأكثر مبيعاً مع إمكانية الإضافة السريعة للسلة والمفضلة.

2. **الأقسام والقائمة (Menu & Categories)**:
   - تصفية فورية حسب القسم (الكل، حلويات، آيس كريم، مشروبات، وجبات).
   - أدوات ترتيب وتصنيف (الأعلى تقييماً، الأقل سعراً، الأعلى سعراً).
   - شبكة منتجات من عمودين مطابقة تماماً للموكاب.

3. **تفاصيل المنتج (Product Details Modal)**:
   - صورة رئيسية للمنتج مع مؤشرات التمرير وشارة "الأكثر مبيعاً".
   - أزرار المشاركة والمفضلة.
   - اختيار النكهات (كلاسيك، بندق، فانيليا، كراميل).
   - اختيار الحجم (صغير، وسط، كبير) مع احتساب الفارق السعري تلقائياً.
   - مكونات مميزة (شوكولاتة بلجيكية، بندق محمص، كريمة غنية، طبقات متعددة).
   - عداد الكمية وزر أضف إلى السلة مع تأكيد صوتي وبصري.

4. **سلة المشتريات (Cart)**:
   - قائمة العناصر مع إمكانية تعديل الكمية أو الحذف.
   - حقل كود الخصم وتطبيقه الفوري (مثال: `WAZEER`).
   - كارت ملخص الطلب وحساب الإجمالي النهائي.
   - زر متابعة الدفع.

5. **إتمام الطلب والدفع (Checkout Flow)**:
   - مؤشر خطوات (عنوان التوصيل ⬅️ الدفع ⬅️ تأكيد الطلب).
   - اختيار العنوان المحفوظ أو التحديد على الخريطة.
   - موعد التوصيل (الآن خلال 30-45 دقيقة أو موعد لاحق).
   - طرق الدفع (عند الاستلام، بطاقة بنكية، محفظة إلكترونية).
   - حقل ملاحظات الطلب (بدون مكسرات، كتابة إهداء).
   - زر تأكيد الطلب النهائي.

6. **حسابي وطلباتي (Account & Live Tracking)**:
   - كارت المستخدم مع الاسم ورقم الهاتف وتعديل الملف.
   - كارت نقاط المكافآت الذهبي (420 نقطة) مع زر استبدال النقاط.
   - تبويبات الطلبات الحالية والطلبات السابقة.
   - مسار تتبع حالة الطلب بالزمن الفعلي (استلام الطلب ⬅️ قيد التحضير ⬅️ جاري التوصيل ⬅️ تم التوصيل).
   - شبكة الوصول السريع (عناويني، المفضلة، الدعم والمساعدة، التنبيهات، الإعدادات).

7. **تفاصيل الفاتورة (Invoice Details)**:
   - شارة "فاتورة مكتملة ✓".
   - رقم الفاتورة ورقم الطلب والتاريخ واسم العميل والعنوان.
   - جدول تفصيلي للمنتجات والكميات والأسعار.
   - احتساب ضريبة القيمة المضافة 14% ورسوم التوصيل والخصم.
   - رمز التحقق QR Code الأصلي.
   - أزرار: تحميل PDF، مشاركة، وطباعة.

## 🚀 تشغيل التطبيق

### تشغيل على المتصفح (Web Preview):
```bash
npm run web
```

### تشغيل على الأندرويد (Android):
```bash
npm run android
```

### تشغيل على الآيفون (iOS):
```bash
npm run ios
```

### بدء خادم التطوير العام (Expo Go):
```bash
npm start
```
ثم امسح رمز الاستجابة السريعة (QR Code) باستخدام تطبيق **Expo Go** على هاتفك.
